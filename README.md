# Sportifline
This Athlete Management SportifLine is a web-based platform is a one-stop platform designed to streamline competition registration, real-time scoring, fitness tracking, and athlete-coach interactions.

#Features

1. Role-Based Dashboards
The platform provides three dedicated dashboards for Athletes, Coaches, and Organizers, each tailored to the specific needs of the user role.

2. Event Management System
Organizers can create and manage sports events with automated registration and scheduling, eliminating the need for manual coordination.

3. Training Log & Performance Tracking
Athletes can log daily training sessions including activity type, duration, and notes, while coaches review these logs to make data-driven decisions.

*4. Coach-Athlete Communication
A built-in messaging system enables real-time communication between coaches and athletes, ensuring instant feedback and personalized training guidance.

*5. Fitness & Nutrition Recommendations
Athletes can input personal details like age, height, and weight, and the system generates tailored fitness and nutrition recommendations for better performance.

| Role | Capabilities |
|------|-------------|

|  Coach | View athlete profiles, review training logs, send feedback |
|  Organizer | Create events, update scores, generate leaderboards |


# Getting Started

# Prerequisites
- Node.js installed on your system
- A modern web browser (Chrome/Edge recommended)

# Installation

```bash
# Clone the repository
git clone https://github.com/thanushreebs2324-byte/sportifline.git

# Navigate to the project directory
cd sportifline

# Install dependencies
npm install

# Start the server
node server.js


#Usage
1. Open your browser and go to `http://localhost:3000`
2. Register as an Athlete, Coach, or Organizer
3. Log in and access your role-based dashboard
